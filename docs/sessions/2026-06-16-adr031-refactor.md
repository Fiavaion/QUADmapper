# Session 9 — 2026-06-16 — ADR-031 Refactor

**Focus:** Audit-driven keep-and-refactor (ADR-031). Get the success metric working
end-to-end and clear the CRITICAL/HIGH audit items.

## What happened
A full-rebuild-vs-keep question was raised. A read-only 5-specialist audit (renderer,
video, audio, ui, core/architecture) unanimously returned **refactor-in-place** — the rot is
localized to `Application::render()` (a ~2034-line god-function); foundations, GL primitives,
build, and tests are sound. Recorded as [ADR-031](../adr/0031-keep-vs-rebuild.md) (Accepted).

Built a UI smoke harness (`tests/smoke/drive_smoke.ps1`) as the verification gate — it drives
the real app via Win32 scancode input and screenshots the monitors, so the keyboard
vertex-warp + projector output (which unit tests can't reach) can be verified.
