## What was done

### v1.1 polish
- **TD-10** — `SidecarClient` state is now `std::atomic` with a `Starting` state; `startAsync()` runs
  the attach/launch/health-poll on a worker thread (joined in `stop()`/dtor — no orphan, no leak).
  AI-enable shows "connecting…" and the run loop posts the connect outcome. Unit test added.
- **US-104** (ADR-036) — per-quad color correction: 4 uniforms in `quad.frag` applied gain →
  brightness → contrast → gamma before α×opacity; identity values are a mathematical no-op. Inspector
  "Color Correction" section; additive `colorCorrection` `.qmap` field (written only when non-identity).
- **US-101** (ADR-037) — per-quad soft-edge blending: per-edge feather (quad-local UV) + gamma curve,
  multiplied into alpha after color correction. Inspector "Soft Edge Blending"; additive `softEdge`
  field. **Visually verified** (projector quad feathering to black on all 4 edges).
- **Load-path fix** — `syncProjectToScene` (app's scene rebuild on load) hand-copies quad fields and
  was missing the two new members; they round-tripped in the serializer unit test but were dropped on
  the real load path. Fixed.
- **#2 UV test-grid** — `src/renderer/UvTestGrid.*`: pure `generateUvTestGridRGBA` (R/G/B/Y corner
  cells, (u,v) gradient tint, white cell lines) + `makeUvTestGridTexture`/`assignUvTestGrid`.
  Inspector "Apply UV Test Grid" + "UV grid on new quads" toggle (reconciled per-frame via
  `seenQuadIds` so it covers every creation path). New `test_renderer` target (4 tests). Visually
  verified warped on quad + projector.
